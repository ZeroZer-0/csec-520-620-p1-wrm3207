# Report

IEEE conference format (`conference_101719.tex`, `IEEEtran.cls`, `refrences.bib`).

`numbers.tex` and `tables.tex` are generated by `make_report_assets.py` from
`../results/` and `evidence/`, so every number in the text and tables comes from
the run outputs. Do not edit them by hand. Rebuild after any new run:

```bash
python report/make_report_assets.py
cd report && pdflatex conference_101719 && bibtex conference_101719 && pdflatex conference_101719 && pdflatex conference_101719
```

`confusion_matrix.png` and `roc_curve.png` are copies of the files in `results/`.
The commands that produce each evidence file are in `evidence/README.md`.
